# 📱 Compartir Acceso a la Aplicación

## Enlace para otros usuarios

Comparte este enlace con otras personas para que accedan a la aplicación desde sus dispositivos:

### **http://192.168.56.1:3000**

## Acceso desde tu computadora

- Acceso local: **http://localhost:3000**
- Acceso en red: **http://192.168.56.1:3000**

## Requisitos para los usuarios

- Estar conectados a la **misma red WiFi** (o LAN) que la computadora con el servidor
- Usar un navegador web actualizado (Chrome, Firefox, Edge, Safari)

## Pasos para acceder

1. Abre el navegador en otro dispositivo
2. Ingresa el enlace: `http://192.168.56.1:3000`
3. ¡Listo! Podrás usar la aplicación de gestión de inventario

## Nota importante

- Si cambias de red o reinicia la computadora, verifica que el servidor esté ejecutándose
- El servidor debe estar corriendo en `c:\Users\José\Desktop\inventario\PAGINA WEB\Gestion_de_Inventario`
- Para iniciar el servidor, ejecuta: `node server.js`

## Solución de problemas

**Si otros no pueden acceder:**

1. Verifica que estén en la misma red
2. Desactiva temporalmente el firewall (si es necesario)
3. Verifica que la IP sea correcta: 192.168.56.1
4. Asegúrate que el servidor está en ejecución (revisa la consola)
